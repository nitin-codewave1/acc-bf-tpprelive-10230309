# EP-002: Authentication and Password Recovery

Enable users to log in, recover forgotten passwords, reset passwords, and set initial passwords securely.

**Objective:** [[OBJ-002]]

## Stories
- [[US-002-01]] — to log in via a login page/view with validation, and have my session restored and profile managed via an auth context, so I can securely access the app
- [[US-002-02]] — to log in with my email and password, with client-side validation, so I can securely access the system
- [[US-002-03]] — to request a password reset, reset my password, and set a new password on first use, so I can regain or establish account access securely
- [[US-002-04]] — to set or reset my password through a dedicated flow with visibility toggles and error handling, so I can regain secure access to my account
- [[US-002-05]] — to log in with my email and password, with client-side validation, so I can securely access the application and my session is restored on reload
