# TC-002-01: AuthContext login/logout/restore session lifecycle

**Story:** [[US-002-01]]
**Module:** to log in via a login page/view with validation, and have my session restored and profile managed via an auth context, so I can securely access the app

## Preconditions


## Expected Result
Verify AuthProvider's login() stores the session/profile correctly, restore() rehydrates an existing session on mount, setProfile() updates profile state, and logout() clears the session and profile state as expected.

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Call login with valid credentials and capture the stored session and profile | assert_text | `` | session and profile are stored |
| 2 | Mount AuthProvider with an existing stored session and verify restore rehydrates it | assert_text | `` | restored profile matches the stored profile |
| 3 | Call setProfile with an updated profile | assert_text | `` | profile state reflects the update |
| 4 | Call logout and verify session and profile are cleared | assert_text | `` | session and profile are null |
