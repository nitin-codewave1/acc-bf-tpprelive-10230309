# TC-002-03: LoginPage validates email format before submit

**Story:** [[US-002-02]]
**Module:** to log in with my email and password, with client-side validation, so I can securely access the system

## Preconditions


## Expected Result
Verify that validateEmail in src/views/LoginPage.tsx correctly rejects malformed email addresses and that handleSubmit blocks submission / shows an error message when validation fails, and proceeds (calling AuthContext login) when the email is valid.

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Navigate to the login page | navigate | `/login` |  |
| 2 | Enter a malformed email | fill | `[data-testid="US-002-02-email-input"]` | not-an-email |
| 3 | Click submit | click | `[data-testid="US-002-02-submit-button"]` |  |
| 4 | Verify the validation error is shown and the form is not submitted | assert_visible | `[data-testid="US-002-02-email-error"]` |  |

| 6 | Verify the validation error is cleared | assert_visible | `[data-testid="US-002-02-email-error"]` |  |
