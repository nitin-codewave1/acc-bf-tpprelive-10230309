# TC-002-02: Login page renders LoginPage view and handles route-level session redirect

**Story:** [[US-002-01]]
**Module:** to log in via a login page/view with validation, and have my session restored and profile managed via an auth context, so I can securely access the app

## Preconditions


## Expected Result
Verify src/app/login/page.tsx renders the LoginRoute component that wraps LoginPage, and correctly redirects an already-authenticated user or renders the login form for unauthenticated users, supporting secure authentication.

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Navigate to the login route with no session | navigate | `/login` |  |
| 2 | Verify the login form is visible to an unauthenticated user | assert_visible | `[data-testid="US-002-02-login-form"]` |  |
| 3 | Set an authenticated session and navigate to the login route again | navigate | `/login` |  |
| 4 | Verify the authenticated user is redirected away from login | assert_url | `/dashboard` |  |
