# US-009-03: Have each logout recorded as an audit log entry

## Definition

As a **user**, I want to **Have each logout recorded as an audit log entry**, so that **the audit trail shows when every user session ended**.

**Epic:** [[EP-009]]

## Acceptance Criteria
- [[AC-009-03-01]] — Given a logged-in user, when the user logs out, then an audit log entry is written recording the user, tenant, and logout timestamp.
- [[AC-009-03-02]] — Given a logout request fails to complete, when the failure occurs, then no logout audit entry is written for that request and the failure is logged.
- [[AC-009-03-03]] — Given an audit log entry for a logout, when it is viewed in the audit trail, then it is listed with the event type 'logout'.
