# EP-010: Authentication, User Profile & RBAC

Support secure login/logout/refresh, session management, user profile self-service (avatar, phone, activity), and a fine-grained role/permission matrix for controlling access to platform modules.

**Objective:** [[OBJ-002]]

## Stories
- [[US-010-01]] — Admin configures role permission matrix
- [[US-010-02]] — Administer roles and granular permission matrix
- [[US-010-03]] — Manage user profile including avatar and activity history
- [[US-010-04]] — Onboard and manage tenant users
- [[US-010-05]] — User login, session refresh, and logout
- [[US-010-06]] — User logs in and manages their session
- [[US-010-07]] — User manages their own profile
