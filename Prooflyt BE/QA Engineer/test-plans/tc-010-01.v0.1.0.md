# TC-010-01: require_permission dependency denies user without permission

**Story:** [[US-010-01]]
**Module:** Admin configures role permission matrix

## Preconditions


## Expected Result
Verify that app/core/deps.py's require_permission (and require_all_permissions/require_any_permission) correctly raises a permission-denied AppError when the current user's permissions (from current_permissions) do not include the required permission code, and allows the request through when they do. This is core to enforcing RBAC across all API routes.
