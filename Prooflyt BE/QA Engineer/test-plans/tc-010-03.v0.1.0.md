# TC-010-03: Login issues tokens for valid credentials and rejects invalid ones

**Story:** [[US-010-06]]
**Module:** User logs in and manages their session

## Preconditions


## Expected Result
POST to the login endpoint in app/api/v1/auth.py with valid tenant user credentials should return access/refresh tokens (via _session helper), while invalid credentials should return a 401/403 error. Verifies core authentication flow used by all other endpoints.

## Planned Playwright Steps

| # | Instruction | Action | Selector | Value |
|---|---|---|---|---|
| 1 | Navigate to the login page | navigate | `/login` |  |
| 2 | Fill email for a valid tenant user | fill | `[data-testid='us-010-06-email-input']` | validuser_<timestamp>@testmail.com |
| 3 | Fill the correct password | fill | `[data-testid='us-010-06-password-input']` | ValidPass123! |
| 4 | Submit the login form with valid credentials | click | `[data-testid='us-010-06-login-submit']` |  |
| 5 | Verify the user is redirected to the authenticated area, confirming tokens were issued | assert_url | `/dashboard` |  |
| 6 | Start a fresh browser context with no session and navigate to the login page | navigate | `/login` |  |
| 7 | Fill the same email | fill | `[data-testid='us-010-06-email-input']` | validuser_<timestamp>@testmail.com |
| 8 | Fill an incorrect password | fill | `[data-testid='us-010-06-password-input']` | WrongPassword! |
| 9 | Submit the login form with invalid credentials | click | `[data-testid='us-010-06-login-submit']` |  |
| 10 | Verify an authentication error is shown | assert_text | `[data-testid='us-010-06-login-error']` | Invalid |
| 11 | Verify the user is not redirected to the dashboard | assert_url | `/login` |  |
