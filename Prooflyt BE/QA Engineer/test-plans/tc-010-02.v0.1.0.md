# TC-010-02: Refresh and logout invalidate/rotate tokens correctly

**Story:** [[US-010-05]]
**Module:** User login, session refresh, and logout

## Preconditions


## Expected Result
Calling refresh with a valid refresh token should issue a new access token; calling logout should invalidate the session/token so subsequent authenticated requests fail. Ensures auth_token model and auth.py session lifecycle work together.
